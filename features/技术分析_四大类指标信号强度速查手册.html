MACD · 趋势类

Moving Average Convergence Divergence · 平滑异同移动平均线
💡 原理
MACD 本质是"两条均线的差值 + 差值的均线"——用快慢均线的收敛/发散来测量趋势的加速度。 因为 EMA 对近期价格加权更高，当短期均线加速偏离长期均线时说明趋势加速。它是趋势的二阶导数，比单看均线更早发出信号。 DIF（快线） = 12日EMA − 26日EMA DEA（慢线） = DIF 的 9日EMA 柱状图 Hist = (DIF − DEA) × 2
🎯 明确信号强度速查
情形星级方向 / 操作
零轴下方金叉 + 价格在 200MA 之上 + 柱状转正 ★★★★★ +2 强多 · 建仓
底背离（价格创新低但 DIF/柱状图未新低，至少 2 个低点） ★★★★★ +2 反转前兆
顶背离（价格创新高但 DIF/柱状图未新高） ★★★★★ −2 减仓
零轴上方金叉（趋势中加仓点） ★★★★☆ +1 顺势加仓
DIF 上穿零轴 = 长期多头确认 ★★★★☆ +1 中期转多
高位死叉 + 柱状转负 ★★★☆☆ −1 减仓警讯
柱状缩减（动能变化早期信号） ★★☆☆☆ 0 预警
没有背离/位置配合的单纯交叉 ★☆☆☆☆ 0 噪音
⚠️ 关键陷阱
  • 震荡市中 MACD 频繁交叉 → 假信号密集，此时应完全忽略 MACD 转用布林带
  • 零轴上方死叉 ≠ 卖出：强趋势中 MACD 可以在零轴上方多次金叉死叉，只要柱状图不深度转负
  • MACD 独立使用永远无效：必须配合位置（均线/关键支撑）+ 量能

RSI · 动量类

Relative Strength Index · 相对强弱指数
💡 原理
RSI 测量"最近 N 日上涨力量 vs 下跌力量"的相对强度，标准周期 14 日。 股价本身没有边界，但买卖力量的比值有边界（0-100）——当某方过度延伸时，反弹/回落是概率上的必然。 RS = N 日内平均上涨幅度 / N 日内平均下跌幅度 RSI = 100 − (100 / (1 + RS)) 教科书信号胜率低： 单纯 RSI>70 卖出、<30 买入的信号胜率只有 50-55%，因为强趋势中 RSI 可以在超买区停留数月。 真正高胜率的用法必须区分趋势状态——上升趋势中看回踩、下降趋势中看反弹受阻、任何趋势中看背离。
🎯 上升趋势中（价格 > 200MA）
情形星级方向 / 操作
RSI 40-50 回踩企稳（上升趋势中的最高质量买点） ★★★★★ +2 加仓/建仓
底背离（价格新低，RSI 未新低） ★★★★★ +2 反转信号
RSI 20-30 极端超卖（上升趋势中罕见） ★★★★☆ +1 抄底机会
RSI 50-70 运行 ★★☆☆☆ 0 持有
RSI > 85 极端超买 ★★★☆☆ −1 部分止盈
RSI 跌破 40 ★★★☆☆ −1 趋势警讯
🎯 下降趋势中（价格 < 200MA）
情形星级方向 / 操作
RSI 反弹 50-60 受阻（下降趋势中的最高质量卖点） ★★★★★ −2 逢反弹减仓
顶背离（价格新高，RSI 未新高） ★★★★★ −2 反转信号
RSI < 20 极端超卖 + 已止跌 ★★★★☆ +1 技术抄底
⚠️ 关键陷阱
  • 先判断趋势状态再看 RSI——RSI 是"趋势状态感知器"，不同状态解读完全相反
  • RSI 长期>70 在强牛股很常见（如 NVDA 2024 全年）——单凭超买卖出会错过整个主升浪
  • 背离信号最强但形成慢，需要至少 2 个高/低点确认，才算真背离

布林带 · 波动类

Bollinger Bands · 波动率通道
💡 原理
John Bollinger 1980 年代发明，把波动率做成可视化通道。假设价格符合正态分布，2 个标准差覆盖 95.4% 的价格波动——股价触碰上下轨在统计上就是"极端事件"。 中轨 = 20 日移动平均线 上轨 = 中轨 + 2 × 20日标准差 下轨 = 中轨 − 2 × 20日标准差 布林带不预测方向，而是告诉你当前波动状态——在低波动时收窄、高波动时扩张，自适应地识别极端。这在震荡市中尤其有价值。
🎯 位置信号
情形星级方向 / 操作
Bollinger Squeeze 挤压（带宽 6 月最低 20%） ★★★★★ 爆发前奏 · 待方向
上升趋势中触及下轨（回归买点） ★★★★★ +2 建仓
触及上轨 + RSI 顶背离 ★★★★☆ −1 减仓
触及下轨 + 下降趋势中 ★★★☆☆ −1 不接飞刀
沿上轨连续运行（强趋势延续） ★★★☆☆ +1 持有
中轨附近（中性状态） ★★☆☆☆ 0 无信号
⚠️ 关键陷阱 + 进阶指标
%B 指标：(价格 − 下轨) / (上轨 − 下轨)，>1 = 突破上轨、<0 = 跌破下轨、≈0.5 = 中轨
BW 带宽指标：(上轨 − 下轨) / 中轨，< 6 个月最低 20% 分位 = Squeeze 挤压状态
  • 触碰上下轨不是必然反转——强趋势中会沿轨运行数周
  • Squeeze 后突破方向不确定，必须等真突破（放量+K线确认）

Volume + OBV · 量能类

On-Balance Volume · 能量潮
💡 原理
成交量是价格最诚实的验证器——你可以画出漂亮的图形，但你伪造不了成交量。
核心公式：价格是果，成交量是因。

OBV（能量潮）—— 1963 年 Joe Granville 发明的"资金流向累计曲线"： 如果收盘价 > 昨日：OBV += 今日成交量 如果收盘价 < 昨日：OBV −= 今日成交量 OBV 会领先价格，因为聪明的机构总是"先建仓再拉升"——建仓时价格波澜不惊但 OBV 已经上升。
🎯 量价关系四象限（核心）
价 ↑ + 量 ↑ · ★★★★★
健康上涨，趋势可信 → 持有/加仓
价 ↑ + 量 ↓ · ★★
可疑上涨，警惕假突破 → 不追高
价 ↓ + 量 ↑ · ★★★★
恐慌抛售，接近底部 → 反转前兆
价 ↓ + 量 ↓ · ★★★★
抛压衰竭，反弹临近 → 准备建仓
🎯 高质量量能信号
情形星级方向 / 操作
底部放量长阳（转折确认） ★★★★★ +2 建仓
突破关键位置放量（真突破） ★★★★★ +2 追突破
OBV 与价格背离 ★★★★☆ ±2 反转前兆
回调 + 缩量（健康中继） ★★★★☆ +1 加仓
顶部天量长阴（派发确认） ★★★★☆ −2 减仓
突破无量（假突破警讯） ★★★☆☆ −1 观望
横盘缩量 ★☆☆☆☆ 0 无信号
⚠️ 关键定义 + 陷阱
放量的定义（必须量化，不能凭感觉）：
  • 放量：当日成交量 > 过去 20 日平均 × 2
  • 倍量：> 均量 × 3（更强）
  • 天量：> 均量 × 5（通常是转折点或衰竭点）
陷阱：财报日、除权除息日、指数换股日的量能不作数（人为放量而非资金意图）

🎯 5. 四类指标共振使用规则

这是把技术分析从"占卜"变成"概率管理"的分界线。

信号方向共振评分

4/4 全部同向 ★★★★★ 极强共振 → 满仓出手（个股不超过组合 10%）
3/4 同向 + 1 中性 ★★★★ 强共振 → 标准仓位 70-80%
2/4 同向 + 2 反向 ★★ 弱共振 → 观望，等待更好位置
1/4 同向 ★ 噪音 → 远离，不动
━━━ 铁律 1 ━━━
单个 ⭐⭐⭐⭐⭐ 信号不出手
至少 3 类指标同向且各自 ⭐⭐⭐+ 才叫共振
━━━ 铁律 2 ━━━
信号强度 ≤ 2 星时，不行动
技术分析的盈利来自高质量信号的稀少性，不是动作的密集性
━━━ 铁律 3 ━━━
指标共振 < 位置质量 < 量能验证 < 基本面双确认
（每往右一档，信号可靠性翻一倍）

📝 应用示例：你之前发的 0100.HK 报告

MACD：零轴下方金叉 + 柱状转正 → ⭐⭐⭐⭐⭐ +2 强多（教科书底部反转）
RSI：52 中性运行区 → ⭐⭐ 0 中性（无背离、无极端）
布林带：中轨附近 → ⭐⭐ 0 中性（无位置信号）
量能：7 月恐慌放量见底 + 8 月放量拉升 +328% + OBV 上拐 → ⭐⭐⭐⭐⭐ +2 强多（三重验证）

共振结果：2/4 偏多含 2 个五星信号——按共振评分规则属于"强共振"边缘：
• 2 个五星信号（MACD + 量能）已在极高质量位置
• RSI + 布林带虽然给中性，但不是反向，属于"未参与"而非"反对"

→ 综合评级：温和买入 ★★★★（60-70% 仓位），触发条件是等 RSI 突破 50 + 布林带上轨突破。
