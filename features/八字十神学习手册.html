本手册讲的是传统命理体系内部的定义与解释方法，不把它当作已经验证的性格测验、因果模型或预测科学。干支与十神对应关系可以按约定计算；把它们解释成人的能力、性格和际遇，则属于传统取象与推论，两者的证据性质不同。

十神名称里的“官、杀、财、印”，首先都是相对于日主的关系名称。它们不是道德标签，也不能独立决定一个人的婚姻、职业、健康或财富。本手册不提供医疗、投资或法律决策指令。传统解释只作为学习与反思材料。

文中以“甲日主”作为统一教学坐标；另有“乙日主”对照，以及由项目引擎实际计算的完整命盘示例。没有出生资料的“三个天干组合”均为关系演示，不冒充完整真实命盘。

第01章｜怎样使用这本手册

难度：L0 入门｜先修：无｜目标：知道先学什么，以及学到哪里才能开始解释。

四个学习层级

层级 你要掌握的能力 对应章节 达标表现
L0 入门 区分符号、计算、解释 第01章 能说明十神不是十种固定人格
L1 基础 识别日主、五行与十神 第02–14章 换一个日主后仍能重新判十神
L2 进阶 读位置、藏干、根气和整体关系 第15–18章、第22章 不再按数量或名称直接论好坏

“提高”表示推理要求更高，不表示预测更可靠。学习顺序是：日主 → 五行生克 → 阴阳 → 十神 → 位置与力量 → 组合 → 条件化表达。

  2. 看盘遇到术语：先查第24章，再回对应十神章节；不要只查一句关键词就下结论。
  3. 复习巩固：先做第23章，再回看错题对应章节，隔天换一个日主重做。

  • 先学计算关系，再学解释；单个十神不能代替整体分析。

第02章｜四柱、八字与日主：先找准参照点

难度：L1 基础｜先修：第01章｜目标：能在命盘里找到日主，并区分天干、地支与十神。

四柱是什么

年柱、月柱、日柱、时柱，各由一个天干与一个地支组成，共八个字。四柱通常从年到时排列，但软件也可能采用不同方向；先读列标题，不凭左右位置猜。

位置 上面的字 下面的字 初学者先关注什么
年柱 年干 年支 与其他柱的关系，不直接断祖上条件
月柱 月干 月支 月支提供季节背景，常称月令
日柱 日干＝日主 日支 日干是十神计算的中心
时柱 时干 时支 与全局的连接，不直接断晚年或子女

例如日柱为“丙寅”，日主是丙，不是寅，也不是丙寅整柱。十神以这个丙为“我”，其他天干和地支藏干都相对它命名。

先分清三层信息

  • 干支层：甲、乙、子、丑等符号，是盘面的基本材料。
  • 关系层：某个天干相对于日主叫正印、七杀等，这是十神。
  • 解释层：把印星联想到支持、学习等，是传统取象，不是额外算出的事实。

日干本身在排盘界面常标为“日主”“元男”“元女”，不必再重复标比肩；但盘中其他位置如果出现与日干完全相同的天干，关系上就是比肩。

柱位取象怎么用

传统常把年柱联系早年与较远环境，月柱联系成长环境和社会秩序，日柱联系自身与亲密生活，时柱联系较后阶段与产出。它们是组织解读的传统视角，不能当作精确年龄分段，更不能见某柱就推出某位亲属的真实经历。

与当前项目的口径

本项目采用立春分年、十二节分月；出生输入按 UTC+8 标准时间。晚子时、真太阳时等有专门约定。不要把农历正月初一直接当成年柱边界，也不要用公历每月1日直接切换月柱。具体口径见项目 docs/rules/00-流派约定.md；这是产品约定，不宣称所有流派一致。

本章总结 · 复习要点

  • 四柱是八个干支字；日主只是日柱上面的天干。
  • 十神是相对于日主的关系名称，不能脱离参照点。
  • 柱位取象是解释框架，不能凭位置断亲属或年龄事件。

自测：日柱为辛亥，日主是什么？答：辛；亥需要再拆藏干，不能当作日主。

第03章｜阴阳五行：所有十神的底层语法

难度：L1 基础｜先修：第02章｜目标：分清生、克的方向，以及阴阳同异。

十天干的五行与阴阳

五行 阳干 阴干 仅用于记忆的自然比喻
木 甲 乙 生长、伸展
火 丙 丁 光热、显露
土 戊 己 承载、整合
金 庚 辛 边界、整理
水 壬 癸 流动、滋养

自然比喻不等于一个人的真实脾气。例如“甲像树”只是记忆方式，不能因此认定甲日主必然固执。

两条必须会默写的循环

相生：木 → 火 → 土 → 金 → 水 → 木。

相克：木 → 土 → 水 → 火 → 金 → 木。

方向不能颠倒：木生火意味着火获得来源，同时木有输出；木克土表示在该模型中木对土形成约束，不是土克木。

“生”不保证有利：来源过多也可能使结构失衡。“克”不保证不利：适当约束也是传统体系里的组织方式。这里讨论的是符号关系，不是现代物理、生理机制。

把日主放进五种关系

以甲木为我：

问题 对应五行 关系组
谁和我同类？ 木 比劫
我产生什么？ 火 食伤
我约束什么？ 土 财星
谁约束我？ 金 官杀
谁支持我？ 水 印星

换成丙火日主，五组分别变为火、土、金、水、木。**同一种五行，不会永远是同一种十神。**古籍对官、印、财、食的立名，也以这种“我与他者”的生克关系展开，参见《三命通会》卷五“论古人立印食官财名义”。

本章总结 · 复习要点

  • 先记五行方向，再判阴阳；不要先背性格关键词。
  • 日主换了，同一目标天干的十神可能完全改变。
  • 生克是关系，不是天然的吉凶分数。

自测：庚金日主，谁生我、谁克我、我生谁？答：土生我，火克我，我生水。

第04章｜十神怎么算：五类关系乘以两种阴阳

难度：L1 基础｜先修：第03章｜目标：能独立判断任意两个天干的十神关系。

核心定义表

五行关系 阴阳相同 阴阳不同 以甲木为例
同我 比肩 劫财 甲为比肩，乙为劫财
我生 食神 伤官 丙为食神，丁为伤官
我克 偏财 正财 戊为偏财，己为正财
克我 七杀／偏官 正官 庚为七杀，辛为正官
生我 偏印 正印 壬为偏印，癸为正印

**不要把“同性为偏、异性为正”套到所有十神。**它只适合财、官杀、印这三组的命名记忆；比劫和食伤必须按本表。这里“同性”仅指阴阳相同，与人的性别无关。

四步判断法

  1. 定位日主，查其五行和阴阳。
  2. 查目标天干的五行和阴阳。
  3. 先判同我、我生、我克、克我、生我中的哪一种。
  4. 再按阴阳同异选组内名称。

例一：甲见辛。甲木、阳；辛金、阴。金克木，是克我；阴阳不同，所以辛是甲的正官。

例二：乙见辛。乙木、阴；辛金、阴。仍是克我，但阴阳相同，所以辛是乙的七杀。

例三：丁见甲。丁火、阴；甲木、阳。木生火，是生我；阴阳不同，所以甲是丁的正印。

从地支读十神

地支有藏干。以辰藏戊、乙、癸为例，相对丙火分别是食神、正印、正官。软件若只在辰下显示一个“食神”，可能采用本气标签；这不代表辰里只有一个十神。先问清软件显示的是本气还是全部藏干。

十神定义采用本章统一口径。第24章提供全部100组对应表，并与当前项目引擎交叉核对；这只验证关系计算，不验证命理预测。

本章总结 · 复习要点

  • 十神＝五行关系＋阴阳同异，缺少任一项都会判错。
  • 正与偏不是好人与坏人；食神与伤官也不是食物与伤害的字面意思。
  • 先拆地支藏干，再分别判断十神，不能把地支一概化为一个标签。

自测：乙见丁、乙见戊、乙见壬是什么？答：食神、正财、正印。

第05章｜比肩：同类、自主与并肩关系

难度：L1 基础｜进阶提示：涉及强弱时先读第17章｜目标：理解比肩为何既可帮身，也可形成竞争。

定义与识别

与日主五行相同、阴阳也相同，就是比肩。甲见甲、乙见乙、丙见丙，都是比肩。它是“与我同类”的最直接形式，不是命盘里所有朋友的专属代号。

基本解读

传统取象常把它联系自主、同辈、合作、同质竞争。作为现代学习比喻，可以把比肩理解为“与自己处在相近位置的参与者”。这种比喻帮助组织问题，但不能证明命主独立、固执或拥有很多朋友。

怎样从基础读到进阶

  • 日主需要同类支持时：比肩可能构成帮扶，这是结构上的作用，不等于现实中有人无条件帮助。
  • 同类已经很集中时：继续增加比肩，可能增加争用资源或意见难协调的解释空间。
  • 有清晰输出通道时：同类力量也可能转向食伤的表达与产出，不能只停在“竞争”二字。

判断要补上：比肩在哪里、是否有根、是否得令、与财星及食伤怎样衔接。

教学例子与反例

只知道甲日主旁边又出现甲，可以确定“出现比肩”，不能确定“朋友会分走钱”。若甲木本来需要支持，另一甲可能是帮身；若木气已有较强集中而财星承受较大压力，才进一步讨论资源分配。两种条件下，同一名称的解释不同。

可用表达：“传统取象可把这里理解为自主与同辈协作的主题；现实中可通过明确职责来检验是否有帮助。”

避免表达：“比肩多，所以你不听劝，合伙必败。”

本章总结 · 复习要点

  • 比肩的确定定义是同五行、同阴阳；自主和同辈只是取象。
  • 帮身还是争财，必须看整体条件，不能只数比肩个数。
  • 同类力量能否转化为产出，比“好朋友或坏朋友”的标签更值得分析。

自测：甲日主见乙是比肩吗？不是，是劫财。

第06章｜劫财：异性同类、协作与分配

难度：L1 基础｜目标：理解“劫”字不等于抢劫或破财预言。

定义与识别

与日主五行相同、阴阳不同，就是劫财。甲见乙、乙见甲、丙见丁。它和比肩都属于比劫，都是同类关系，只是阴阳配对不同。

基本解读

传统常用同辈协作、竞争、共同投入、资源分配来解释劫财。现代教学可以把它比作“既能帮忙，也有自身诉求的合作者”。这不是对实际同事、亲友品行的评价。

进阶时必须补问

  1. 日主是否确实需要比劫支持？需要时，不能见劫财就排斥。
  2. 财星是否存在，是否有实际受制关系？没有这些条件，“劫财夺财”只是套词。
  3. 是否有官杀约束比劫，或食伤承接同类力量？全局可能有不同流向。
  4. 所谓竞争是盘面取象，还是现实中已有可观察的分配冲突？两者要分开记录。

教学例子与反例

甲日主见乙，可以描述同类力量参与。若另有己土正财，再看到木对土的约束关系，才进入比劫与财的组合讨论；但仍不能由此断言被骗、亏损或亲友不可靠。

反过来，在需要木气支持的结构里，乙可能参与帮身。因此“劫财一律为忌”不成立。

可用表达：“可以把分工、预算和成果归属讲清楚；这是一种通用的合作管理方法，不是盘面证明有人会占便宜。”

本章总结 · 复习要点

  • 劫财是异阴阳的同五行关系，名称本身没有犯罪或道德含义。
  • 与财星有关系，不等于现实必然损失钱财。
  • 学会比较支持作用、资源压力和制泄路径，而不是给人贴标签。

自测：为什么劫财有时能帮身？因为它仍与日主同五行。

第07章｜食神：输出、表达与持续产出

难度：L1 基础｜目标：理解“我生”的方向，以及食神与享受、产出的关联。

定义与识别

日主所生、阴阳相同的天干为食神。甲生丙，丙是甲的食神；乙生丁，丁是乙的食神。定义的核心是输出，不是字面上“爱吃”。古籍的食神论述同时涉及生财、制杀等配合，不能只摘出一个性格词，参见《三命通会》卷六“论食神”。

基本解读

传统取象常见表达、技能、作品、滋养和生活体验。现代教学可用“把已有资源变成可分享成果”来理解，例如整理知识、讲解方法、完成作品。是否真的有这些能力，仍要看学习和表现。

条件不同，作用不同

  • 来源足、输出有承接：可讨论较连贯的产出关系。
  • 日主本来就缺乏支持，食伤再集中：需要讨论输出负担，不能自动美化。
  • 食神能够连接财星：进入食神生财的结构问题。
  • 食神对七杀形成有效约束：进入食神制杀的结构问题。
  • 偏印对食神形成不利压制：再讨论枭印夺食，不能一见偏印就套用。

教学例子

甲木 → 丙火 → 戊土，分别是日主 → 食神 → 偏财。这是一条五行相生关系链。用现代比喻，可以讨论“能力产出怎样连接现实资源”，但不能因此保证创业成功或获得收入。

反例：只有一个丙字，既没有分析其根气，也没看财星和其他关系，就直接断“享福、有口福”，信息不足。

本章总结 · 复习要点

  • 食神首先是同阴阳的“我生”，主线是输出关系。
  • 食神生财、食神制杀都是需要条件的组合，不是见字即成立。
  • 产出需要来源和承接；食神不是越多越好。

自测：庚金日主的食神是什么？答：壬水。

第08章｜伤官：输出、质疑与规则之间的张力

难度：L1 基础｜目标：把“伤官”从骂人的标签还原为关系名称。

定义与识别

日主所生、阴阳不同的天干为伤官。甲见丁、乙见丙、丙见己。它与食神同属食伤，因此两者共同的底层机制都是输出。

基本解读

传统取象常把伤官联系表达锋芒、辨别、质疑和不拘成规。现代学习可以联想到提出不同意见或改进流程，但不能把它等同于高智商、反社会、不服管或某种婚姻命运。

食神与伤官的“温和／锋利”区别只是常用教学印象，不是每个人都符合的硬定律。

为什么会谈“伤官见官”

以甲为例，丁是伤官，辛是正官；丁火克辛金，因此传统会分析输出对官星秩序的影响。但“丁与辛同现”只是起点，仍要看位置、强弱、是否有中介、官星在结构中是否需要保护。

如果丁火弱而辛金有力，作用程度不能按字面夸大；如果财星形成食伤生财、财再生官的通道，解释也不应停留在一句凶断。

教学表达

可用：“这个组合适合讨论表达方式与规则要求的协调。现实中可以先说明依据，再提出替代方案。”

不可用：“伤官旺，所以婚姻不好，必与领导冲突。”

这里的沟通建议只是普遍可用的方法，不是由命盘验证的个人行为预测。

本章总结 · 复习要点

  • 伤官属于我生，与食神共享输出这一主线。
  • “伤官见官”要分析作用链，不能直接翻译成灾祸。
  • 才华、反叛、婚姻等现实判断不能由一个术语推出。

自测：丁火日主见戊土是食神还是伤官？答：伤官，阴阳不同。

第09章｜正财：可管理的资源与责任

难度：L1 基础｜目标：理解财星是我克关系，不等于账户余额。

定义与识别

日主所克、阴阳不同的天干为正财。甲木克己土，己是甲的正财；乙木克戊土，戊是乙的正财。

基本解读

财星在传统体系中涉及可支配对象、资源、经营与责任。正财常被现代教学解释为有秩序的资源管理、持续经营、投入与回报的对应。这些是帮助记忆的取象，“正财＝工资”不是定义。

古书还常用财星对应婚姻角色，那与古代家庭制度和性别分工有关。本手册不把这种角色映射当成现实关系事实，更不据此评判伴侣价值。

为什么财多不一定好

财星增加的是“我克对象”的力量，并不自动增加日主处理它的条件。传统所谓“能否任财”，需要看日主支持、食伤来源、比劫介入及官杀关系，不能只看财的数量。

强弱与承担能力是体系内的比喻，不代表实际财务能力已经经过测量。

教学例子

甲日主见己，可确定正财出现。若再有丁火，丁为伤官，火生土，构成食伤生财方向；若又有癸水正印，土克水，则还要考虑财与印的关系。一个己可能同时参与多条关系，不能只选择有利的一条讲。

可用表达：“可以围绕资源使用与责任分配提问。”

避免表达：“正财透干，所以有稳定高薪，适合买房。”

本章总结 · 复习要点

  • 正财是异阴阳的我克关系，不是财富数额。
  • 稳定收入只是常见联想，职业、工资和投资选择不能直接推出。
  • 财星要连同日主、食伤、比劫和印星一起读。

自测：壬水日主的正财是哪一干？答：丁火。

第10章｜偏财：资源调配、机会与流动

难度：L1 基础｜目标：理解偏财为何不等于横财或赌博运。

定义与识别

日主所克、阴阳相同的天干为偏财。甲见戊、乙见己、丙见庚。

基本解读

偏财常被传统及现代教学联系较广的资源接触、流动安排、机会和交换。它与正财的共同点都是财星，差别首先是阴阳配对；“正财是上班、偏财是做生意”只是很粗的类比，并非对应职业的固定规则。

“偏”不是违法或不正当。偏财也不提供彩票、短线交易或投资回报的依据。

进阶观察

  • 资源从哪里来：是否有食伤相生，还是财星孤立？
  • 资源能否承担：日主有何支持，是否与其他力量失衡？
  • 资源流向哪里：财可以生官杀，也可以克印，未必停留为个人所得。
  • 哪些只是现代联想：社交广、商业嗅觉等必须用现实表现验证。

教学例子

丙火日主见庚金，庚为偏财；若同时见壬水，壬是七杀，金生水，可分析财生杀这一方向。不能只看到庚就说“机会多”，而忽略它可能增强了另一个约束因素。

反例：没有透出偏财，不代表没有商业能力；财可能藏在地支，现实收入更不能由一个符号是否出现来决定。

本章总结 · 复习要点

  • 偏财＝同阴阳的我克；“偏”没有道德含义。
  • 机会与流动是取象，偏财不等于横财、投机成功或幸运概率。
  • 看资源的来源、承担与流向，比猜收入方式更有条理。

自测：辛金日主的偏财是什么？答：乙木。

第11章｜正官：秩序、约束与角色要求

难度：L1 基础｜目标：理解官星如何约束日主，以及为什么不等于当官。

定义与识别

克制日主、阴阳不同的天干为正官。甲见辛，乙见庚，丙见癸。基本定义可与《三命通会》卷五“论正官”对读；古籍里的仕途评价不应直接搬成现代职业预测。

基本解读

正官常被联系制度、标准、职责、评价和边界。用现代比喻，可以理解为“外部世界对自己提出的明确要求”，例如流程和岗位责任。命盘有正官不等于现实中守法、有职位、道德高尚，也不等于一定适合体制内工作。

约束为什么可能有两面

有支持和承接时，约束可被解释为组织能力与承担责任的主题；约束集中、日主缺乏支持时，则要讨论负担。传统结构的有效与否不能替代对现实压力、能力及环境的观察。

需要查看：官是否得令、有根；是否得到财的生助；是否通过印星连接日主；是否受到伤官作用；是否与七杀同现而需要区分路径。

教学例子

甲日主，辛为正官，癸为正印。辛金 → 癸水 → 甲木，是官生印、印生身的方向。它可以作为“要求—学习支持—承担”的教学比喻，但三个天干同现不等于已经成格，更不保证考试、升职结果。

本章总结 · 复习要点

  • 正官是异阴阳的克我关系，核心是约束，不是官职。
  • 官星是否发挥所需作用，取决于力量、位置和连接方式。
  • 官印相生先是一条关系链，不能直接当作学历与职位承诺。

自测：为什么甲见庚不是正官？因为庚与甲同为阳，故为七杀。

第12章｜七杀／偏官：较强约束与应对方式

难度：L1 基础；制杀、化杀属于 L3｜目标：能区分“有七杀”和“七杀如何发挥作用”。

定义与名称

克制日主、阴阳相同的天干为七杀，也称偏官。甲见庚、乙见辛、丙见壬。名称中的“杀”不等于死亡或灾难。以甲起顺数天干到庚为第七位，可帮助记名，但真正判定仍用生克与阴阳。

部分传统论述会按有无制化区分“偏官”“七杀”的使用语境；不少现代排盘软件把两者作为同一十神的别名。本手册先统一关系定义，再单独讨论制化，不因名称不同偷偷改变计算。

基本解读

常见取象是压力、竞争、挑战、较直接的约束。现代比喻可用“要求高、时间紧的任务”。但不能因此认定一个人暴躁、危险、遭遇灾祸或适合军警等某一职业。

两种常见处理路径

  • 制杀：用另一个五行对七杀形成约束，例如甲日主的丙食神为火，庚七杀为金，火克金。
  • 化杀：通过相生的中介连接日主，例如庚金 → 壬水 → 甲木，杀生印、印生身。

制，是约束；化，是转接。它们不是同一机制，也不是看到相关几个字就自动成立。要检查双方有无力量、相互能否作用、是否受到别的关系干扰。

反例与表达

有庚而无有效制化，不能照搬“食神制杀”；有庚和丙但丙缺乏条件，也不能仅凭同现宣布结构成立。反之，有七杀而配合得当，也不能只按名称判凶。

可用表达：“传统结构里存在较明显的约束因素，需要继续检查支持与应对通道。”

本章总结 · 复习要点

  • 七杀是同阴阳的克我，不是现实伤害的预告。
  • 制杀与化杀机制不同；能否成立要看力量与配合。
  • 先问“怎么应对这股约束”，不要先贴吉凶标签。

自测：甲日主的食神、七杀分别是什么？答：丙、庚；丙火克庚金。

第13章｜正印：支持、学习与承接

难度：L1 基础｜目标：理解“生我”的意义，不把印星数量等同于学历。

定义与识别

生助日主、阴阳不同的天干为正印。甲见癸、乙见壬、丙见乙。古籍“印绶”论述以生我为基本关系，可参见《三命通会》卷六“论印绶”。不同文献里的“印绶”有时泛指印星，不要一看到这两个字就认定只指正印。

基本解读

传统常把正印联系庇护、支持、传承、学习与资格。现代教学可联想教材、导师、训练和制度化支持，但这些只是类比。印星不是学历证书，也不是考试分数。

为什么印也不是越多越好

日主需要支持时，印有生助方向；如果已有较集中的支持而缺少输出，传统可能讨论印重、流通不畅。现代比喻是“输入和实践如何衔接”，不能由此诊断懒惰、依赖或心理状态。

印还可能受到财星约束，也可能承接官杀。要区分：是支持被削弱，还是本来过重的支持获得调节。不能把“财克印”一概翻译成学业失败或亲属有事。

教学例子

甲日主见癸，为正印；再见辛正官，构成官生印方向。若又见己正财，己土克癸水，便出现财印之间的关系。分析必须把三者一起读，不能只摘取“官印相生”四字。

可用表达：“可围绕学习资源与实际应用之间的衔接提出问题。”

本章总结 · 复习要点

  • 正印是异阴阳的生我关系，支持是主线。
  • 学历、考试、母亲状况等都不能由印星独立推出。
  • 有多少支持、支持如何被使用，要与食伤、财、官杀一起看。

自测：丙日主见甲是正印吗？不是，甲丙同为阳，甲是偏印。

第14章｜偏印：另一种支持路径与专门理解

难度：L1 基础；枭印夺食属于 L3｜目标：区分偏印的关系定义与不利组合名称。

定义与识别

生助日主、阴阳相同的天干为偏印。甲见壬、乙见癸、丙见甲。它首先仍属于印星，即生我关系，不是孤僻、偏执或疾病的标签。

基本解读

常见教学取象是非标准学习、专门领域、独立理解和独特支持方式。可以用“自学或跨领域研究”帮助记忆，但正印并非只会应试，偏印也不保证研究能力或特殊天赋。

偏印、枭神、枭印夺食怎么分

“偏印”是固定的十神身份；“枭神”在一些文献和软件中用作偏印别称，在另一些语境里强调其对食神的不利作用。阅读时先查作者的定义。

以甲为例，壬是偏印，丙是食神，壬水克丙火，存在印克食方向。只有进一步判断食神是否为所需、偏印是否有效作用、是否有其他救应，才有理由讨论“夺食”这类不利结构。不能见壬就自动说“枭神夺食”。

教学例子与反例

甲—壬—丙只展示三个身份及水克火的方向，不足以给出人生结论。若食神并不是结构重点，或偏印本身无力，断“作品受阻”“子女有问题”都属于越级推断；后者尤其不能作为现实家庭判断。

可用表达：“学习输入与表达输出的关系值得梳理，但需要更多整体条件。”

本章总结 · 复习要点

  • 偏印与正印同属生我；区别首先是阴阳配对。
  • 偏印身份与“枭印夺食”组合不能混为一谈。
  • 专门研究是现代记忆类比，不是天赋或心理诊断。

自测：甲日主的偏印怎样作用于食神？答：壬水对丙火有克制方向；是否构成不利组合仍待判断。

第15章｜五组对照：相似不等于相同

难度：L2 进阶｜先修：第04–14章｜目标：能比较十神，而不是背十份互不相干的性格说明。

先比较共同机制，再比较组内差别

组别 共同机制 阴阳同／异 可用于记忆的观察角度 最容易犯的错
比肩／劫财 与我同类 比肩同，劫财异 自主、合作、同辈与分配 把劫财当成坏朋友
食神／伤官 我生，向外输出 食神同，伤官异 表达、作品、实践与质疑 食神一定温柔，伤官一定叛逆
偏财／正财 我克，面对资源对象 偏财同，正财异 管理、交换、投入与责任 偏财就是彩票，正财就是工资
七杀／正官 克我，外部约束 七杀同，正官异 压力、标准、要求与秩序 七杀必凶，正官必贵
偏印／正印 生我，输入与支持 偏印同，正印异 学习、训练、传承与承接 正印高学历，偏印有神秘天赋

表中观察角度是教学取象，不能把“同阴阳”理解成现实作用必然更强，也不能把“异阴阳”理解成更温和。实际强弱必须另看条件。

五组怎样连成整体

在五行相生的抽象层面，可以写成：

比劫 → 食伤 → 财 → 官杀 → 印 → 比劫。

例如甲木为中心，木生火、火生土、土生金、金生水、水再生木。它帮助理解“一个因素可能同时支持下一环节”，但不是一条人生必经路线，也不是只要五组齐全就优越。

在相克层面，常见观察有：比劫克财、财克印、印克食伤、食伤克官杀、官杀克比劫。这里描述的是组别五行方向；具体到某个正偏十神，还要重新核对天干，而不是把每种组合都叫同一个格名。

一个比较练习

甲见丙与甲见丁，同属输出；区别在阴阳。甲见丙、丙再见庚时，可以检查食神制杀；甲见丁、丁对辛作用时，可以检查伤官与正官。先有具体天干关系，后有组合名称。

本章总结 · 复习要点

  • 每一组先有共同生克机制，再有阴阳差别。
  • 不要把现代职业和性格比喻当作十神定义。
  • 整体分析要看关系链，不是把十个关键词拼成一段话。

自测：印星一定只“帮助”吗？不是，它还对食伤有克制方向；是否有利须看全局。

第16章｜透干、藏干、通根与月令：名称之外的信息

难度：L2 进阶｜先修：第02–04章｜目标：能回答某个十神出现在哪里、有没有支持。

四个关键术语

术语 基本含义 确定事实与解释的边界
藏干 地支所藏的天干 可按采用的藏干表查出，不等于现实中的秘密
透干 地支所藏天干出现在天干层面 “哪个字在何处出现”可核对；“因此一定显贵”不是事实
通根 天干在地支得到同类根气支持 狭义、广义及根气等级划分有差异，应说明口径
月令 月支所代表的季节背景 不是公历月份，也不能只看农历月名就替代排盘

一个字如何同时具有不同描述

甲日主坐寅，寅中藏甲、丙、戊。甲在寅中见本身，可以作为清楚的通根例子；寅中丙对甲是食神，戊对甲是偏财。若另一个天干也出现丙，可以说寅中丙透出。

同类根与本干根怎样分级、墓库中的根怎样计力，各家并不完全相同。本手册只在明确藏有本干时使用最直观的例子，不把有争议的细分包装成统一规则。

透出不等于强，藏着不等于没有作用

一个天干虽然透出，仍可能失令、无根或受制；一个藏干虽然不透，也可能处在关键位置，或在后续配合中被重视。因此“天干看得到就是强，地支看不到就是弱”不成立。

为了先学清楚，可使用四栏记录：身份—位置—支持—受制。例如“辛为正官，见于月干；有无酉等支持待查；是否受火作用待查”。不要在后两栏没填时，直接跳到结论。

月令为什么重要

月令提供季节背景，是传统判断力量和格局的重要起点。春木、夏火、秋金、冬水是粗略记忆；辰戌丑未的土、月内进退气、寒暖燥湿等更复杂。不能把四季口诀当作精确权重表，也不能用四个字的数量盖过季节与根气。

本章总结 · 复习要点

  • 十神回答“是什么关系”；透藏根令回答“在哪里、有什么条件”。
  • 透出与有力不是同义词，藏干与无作用也不是同义词。
  • 先把条件写完整，才有资格讨论作用大小。

自测：甲坐寅为什么比“甲旁边有一个木字”更具体？因为明确查到了寅中藏甲这一根气事实。

第17章｜旺衰、身强身弱与制化：不要用数数替代分析

难度：L2 进阶｜先修：第16章｜目标：知道判断力量需要哪些信息，以及哪些捷径不可靠。

“身”与“强弱”指什么

“身”指日主。身强身弱描述的是传统模型里日主相对其他力量的状态，不是身体健康、意志坚强、社会地位或人的价值。不能把身弱解释成体弱多病，也不能把身强解释成优秀或强势。

一个基础检查顺序

  1. 月令与时令：日主处在怎样的季节背景？
  2. 根气：地支有没有支持，位置和状态如何？
  3. 生助：印与比劫是否有力，能否实际连接日主？
  4. 克泄耗：官杀克、食伤泄、财的消耗关系怎样分布？
  5. 组合变化：合冲制化有没有改变前面看到的条件？
  6. 保留不确定性：若口径冲突或条件不足，先写“暂不定强弱”。

这不是通用打分算法。某些流派重格局成败，某些重扶抑，某些重调候；它们的问题意识不同，不宜混成一张没有说明来源的“能量分数”。

克、泄、耗、生、扶怎样区别

术语 与日主的关系 甲木例子
生 印星生我 水生木
扶 同类帮助 木与木同类
克 官杀制约我 金克木
泄 我生食伤 木生火，属于输出
耗 我去克财 木克土，传统视为承担对象所需的消耗

“耗”是命理解释用语，不是经过测量的生理能量。不同结构下，克泄耗不一定都是坏事，生扶也不一定都需要。

两个必须会说的反例

  • 盘里木字较多，不代表木一定旺：还要看季节、根气和受制。
  • 命盘五行齐全，不代表比缺一种更好：是否需要该五行是另一个问题。

《滴天髓》的体用讨论强调不能只看一个方面；本手册据此采用“列条件、看配合”的学习方式，而不照搬其古代吉凶断语。参见《滴天髓·体用论》。

本章总结 · 复习要点

  • 身强身弱不是健康诊断或人格评价。
  • 数量只是信息之一，月令、根气、生助和制化都要看。
  • 五行不齐不能直接推出“缺什么补什么”。

自测：“缺水就用蓝色物品补水”能从本章推出吗？不能；先不论现实有效性，连该盘是否需要水都尚未判断。

第18章｜合、冲、刑、害、破：先记关系，再谈条件

难度：L2 进阶 → L3 提高｜目标：识别常见关系，避免“合必好、冲必坏”。

入门必须认得的几组

类别 常见组合 学习时的注意点

地支六冲 子午、丑未、寅申、卯酉、辰戌、巳亥 有冲的关系，不等于发生事故

常见刑的整理：寅巳申、丑戌未、子卯，以及辰、午、酉、亥的自刑说。三刑是否须齐、两支如何论、是否采用全部自刑条件，不同流派存在差异。本章用于识词，不把简表当作无条件的事件预测器。

三个容易混淆的层次

  1. 关系存在：盘里同时见甲和己，可核对有五合配对。
  2. 关系作用：是否贴近、是否有争合、受何种环境影响，须继续分析。
  3. 合化成立：是否具备采用流派要求的季节、支持、排除干扰等条件，要求更高。

不要从第一层直接跳到第三层。初学者写“有甲己合的关系，是否合化暂不判断”是合格表达。

为什么同一对地支可以有多个标签

某些配对在不同关系表中重复出现，不是表格自动出错。例如巳申可同时被列入合、破，并涉及刑的讨论。应该列清采用哪些规则，再看结构，不要强行只留一个“好”或“坏”的标签。

关系与现实之间隔着什么

“子午冲”只能确定一组传统符号关系。若进一步联想到变动或张力，必须明示这是取象；不能据此断交通事故、分手、搬家或某个具体月份发生灾祸。

本章总结 · 复习要点

  • 配对存在、发挥作用、合化成立，是三个不同层次。
  • 合不保证有利，冲不保证有害；作用对象与条件更重要。
  • 同一配对可能有多种关系，不能用单标签覆盖全局。

自测：甲己同时出现，能否直接把所有甲木都改算成土？不能，合化条件尚未建立。

第19章｜常见组合：读懂名称背后的作用链

难度：L3 提高｜先修：第15–18章｜目标：能解释组合如何形成、何时不能成立。

学组合的通用方法

每看到一个组合名，问五件事：相关十神是谁 → 作用方向是什么 → 是否有力 → 是否被干扰 → 这个作用是不是结构所需要的。“同现”与“有效作用”不同，“有效作用”与“格局成立”也不同。

三组最需要细读的例子

食神制杀与杀印相生：前者用火克金来约束杀，后者经金生水、水生木来转接杀。不是简单“食神和印越多越好”；两种路径并用时，还要看印是否影响食神，不能把所有吉名叠加。

财克印与财破印：“克”是五行方向，“破”已经含有对某种结构受损的判断。若印本来偏重，财的作用在某些分析中反可能被视为调节。不能把所有财印同见都称为破印。

官杀混杂：一般涉及正官、七杀并见，但具体要求——是否同透、轻重是否相当、能否去留——不同论法并不一致。官藏支、杀透干，不能不说明口径就下一个完整混杂结论，更不能推出感情混乱。

把断语改成分析句

错误：“食神制杀，所以一定成大事。”

合格：“这里存在食神作用于七杀的关系。是否达到有效制杀，还需检查食神来源、七杀力量及其他干扰；目前只能记录为待分析的组合。”

传统对成败与救应的讨论本身就要求四柱配合，参见《子平真诠·论用神成败救应》原文录本。本章的现代类比是教学重述，不是古籍原话。

本章总结 · 复习要点

  • 先讲作用链，再讲组合名；同现不等于成格。
  • 制与化、克与破，各自不是同义词。
  • 每个组合都应写出成立条件与反例，不能只摘吉名。

自测：甲、庚、壬同时出现，为什么还不能宣布杀印相生格成立？因为尚未检查根令、力量、位置、干扰及结构所需。

第20章｜格局、用神、喜神与忌神：同一个词可能有不同用法

难度：L3 提高｜先修：第16–19章｜目标：能辨认分析路线，不把不同体系的“用神”混成一回事。

先问：这里的“用神”是什么意思

分析路线 主要关心的问题 “用神”常见用法 常见误读
月令格局取向 月令与四柱如何形成、维持某种结构 以月令为重要起点，辨格局及配合 直接等同于“补身弱的五行”
扶抑取向 日主及各力量如何取得适当关系 选择需要的生扶、克泄耗因素 身弱就只加印比，身强就只加财官
调候取向 季节寒暖燥湿怎样协调 讨论调节气候意象的因素 把寒暖当医学诊断，或把喜火变成现实补火方案
通关取向 两股力量相持时怎样转接 寻找相生中介 只要中间五行出现就自动化解冲突

这些是常见分析侧重点的整理，不是严格互斥的四个统一门派；具体作者可能并用，但应解释先后与条件。

《子平真诠》以月令及四柱配合讨论用神变化和成败，不能未经说明就用现代“平衡补缺”替换其所有词义。参见“论用神变化”原文录本。电子录本可能含底本异文或录入讹字，应对照影印，不照抄有疑问的例句。

格局不是十神标签的别称

“命盘里有正官”与“按某种口径取正官格”不是一回事。前者是出现事实；后者需要月令、透藏、配合等判断。正官格也不等于社会地位较高，更不能据此给人的价值排序。

喜神与忌神怎样理解

在已经明确的分析路线中，帮助所需结构的因素常称喜，妨碍所需结构的因素常称忌。喜忌依赖前提，不能脱离整体固定说“每个甲木都喜水”或“每个身弱盘都怕财”。

“相神”常用于讨论辅助、维护格局的关键配合因素；具体定义仍应跟随作者语境，不宜直接与喜神完全画等号。

提高版的三条自律

  1. 不先定结论，再到盘里搜支持它的字。
  2. 不把不同口径中各自有利的部分拼成一个“全优命盘”。
  3. 条件不足时写明“未定用神”，比给出没有依据的精确答案更专业。

本章总结 · 复习要点

  • 用神是有语境的术语，必须先说明采用哪一种分析路线。
  • 有某十神、形成某组合、取某格局，是不同层次。
  • 喜忌依条件成立，不等于固定补缺清单。

自测：为什么“命里缺金，所以金是用神”不成立？因为缺少与需要是两个问题，且没有说明用神口径。

第21章｜大运、流年与原局：变化怎么读

难度：L3 提高｜先修：第19–20章｜目标：理解时间层次，不把新增十神当作确定事件。

三个时间层次

层次 传统用途 不应理解成
原局 出生四柱作为分析起点 一张决定全部人生的剧本
大运 按既定排运口径分段考察的干支背景，通常每步十年 十年必然好或坏的评级
流年 按采用的年界口径加入当年的干支 一年中每件事都有预告

排大运的顺逆、起运时刻与年龄口径需另外计算。本项目采用的顺逆规则与虚岁标示属于产品约定；不要把界面“某岁起运”直接当成精确公历生日交运。

新增一个字，怎么分析

以甲日主为例，流年天干庚可判为七杀。但后续至少有四个问题：

  1. 原局是否已有庚或其他官杀？新增因素是什么？
  2. 庚与原局的食伤、印、财等如何作用？
  3. 流年地支和大运干支是否改变支持或关系？
  4. 这些是体系内的结构解释，能否与现实观察相互区分？

不能省去前面三步，直接写“七杀年必有压力或事故”。即使把“必”改成“大概率”，若没有统计证据，仍不能伪装成概率预测。

高频术语

  • 岁运并临：大运与流年干支相同的传统称谓；不是必然发生灾祸。
  • 伏吟：常指干支等重复，但不同术数和论法细节有别；先说明哪一层重复。
  • 反吟：涉及对冲等关系的传统用语，具体定义须跟随所用体系；不能和奇门盘的星反、门反直接混用。
  • 引动：某因素在新增时间背景下被重新重视的解释词；应说清到底新增了哪个字、触发哪条关系，避免空泛。

本章总结 · 复习要点

  • 大运、流年是在原局基础上加条件，不是独立吉凶标签。
  • 新增字的十神可以确定，现实事件不能直接推出。
  • 年界、交运时间和年龄口径必须说明，不能混用。

自测：甲日主走庚运，能否只看“七杀”决定职业变动？不能，既缺整体配合，也缺现实信息。

第22章｜完整示范：从读盘事实到谨慎解释

难度：L2 进阶 → L3 提高｜目标：用同一张盘演示完整工作顺序，不把步骤省略成一句断语。

八步解读工作表

  1. 核对输入：公历或农历、出生时间、时区、经度校正、年界月界与晚子时口径。
  2. 定位日主：写出日干、五行和阴阳。
  3. 列十神：分别列天干与全部藏干，不遗漏阴阳。
  4. 看月令与根气：先记录事实，再判断力量；不急于定身强弱。
  5. 列作用链：生助、输出、财、官杀之间如何连接，哪些只是同现。
  6. 说明分析路线：格局、扶抑、调候等采用什么，未定的就明确未定。
  7. 分开事实和解释：事实可以回查，解释必须标出条件与限制。
  8. 写出不能推出什么：不从术数给健康诊断、财务决定、法律结论或亲属命运判断。

  • 壬水克丙火，阴阳相同，所以时干壬为七杀。

正官癸藏于辰，七杀壬透于时干。可以分别记录两者存在；是否称官杀混杂、是否构成所采用流派中的问题，必须先给出判据，不能自动套名称。

以丙火为日主，天干可见两处偏财和一处七杀；日支寅含偏印、比肩与食神，月时支辰含食神、正印与正官。盘面同时涉及资源、约束、支持与输出等传统关系。若进一步解释，应先核对辰月的季节条件、根气与各因素的作用方式；目前这些信息不足以直接判断事业高低、收入水平或性格定型。

这段文字不追求“神准”，而是把能确定和不能确定的内容交代清楚。

本章总结 · 复习要点

  • 可确认的是干支与关系；整体强弱、格局和取象需要更多条件。
  • 完整解读应有输入口径、事实清单、分析路线和不确定性。
  • 能说明“目前不能推出什么”，也是合格解读的一部分。
