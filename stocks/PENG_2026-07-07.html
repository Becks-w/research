🎯 核心比喻
Penguin 像 AI 数据中心的「专业装修承包商 + 建材厂」二合一——客户买了一大堆英伟达 GPU（毛坯房里的核心设备），却不知道怎么把它们组装、散热（浸没式液冷）、调试成一座能真正跑起来的「AI 工厂」；Penguin 就是那个设计、施工、部署、再帮你长期托管运维的总包工头（目前管理着 7.5 万+ 块 GPU）。同时它自己还开了一家「建材厂」，生产 AI 时代刚需的高可靠内存模组。旁边还有一个正在关停的老式灯具作坊（LED）。

📦 商业模式三问

① 卖什么？
卖三样东西，权重悬殊：① Advanced Computing（约占收入34%）——把裸 GPU 变成可靠 AI 集群的「交钥匙工程」+ 托管软件运维，外加 Stratus 容错计算这种「永不宕机」的利基产品；② Integrated Memory（约占50%，SMART Modular 品牌）——DRAM 内存模组、「零失效」内存、CXL 内存扩展器，这是 AI 推理吃内存的直接受益品；③ Optimized LED（约占16%，Cree LED）——传统 LED 照明芯片，逐年萎缩、管理层在主动收缩。真正的成长引擎是①和②。
② 怎么收费？
混合收费模式，可预测性一般：Advanced Computing 是「项目制硬件（低毛利、一次性、金额lumpy，一个主权AI或大企业单可达几千万美元）+ 高毛利经常性服务/软件/托管」的组合；Integrated Memory 是「按量卖内存条」，单价随内存周期上下波动——现在是涨价+AI需求的上行周期（Q2 该板块 +63% YoY）；LED 是一次性硬件销售，萎缩中。整体 non-GAAP 毛利率约 31%，管理层喊出长期 40% 目标，但那需要服务占比和 CXL 高毛利产品同时放量。
③ 客户为什么必须买？
三重动机：① 速度+专业性驱动——企业/主权客户想快速建 AI 算力，但缺乏把裸 GPU 变成可靠集群的工程能力，Penguin 帮他们省去自建团队的时间和试错成本；② 可靠性恐惧驱动——Stratus 容错 + 「零失效」内存卖给不能宕机的金融、电信、工业客户，一次宕机的代价远高于溢价；③ 内存是运营刚需——AI 推理撞「内存墙」，CXL 内存扩展（单机可加 11TB）是绕不开的基础设施。这三点决定了它在服务/内存端有一定定价权，但在纯硬件端仍是价格竞争。

💼 客户结构 + 护城河金融比喻

具体客户名单 + 客户分层
客户结构偏「项目型/橄榄型」，大单驱动、集中度曾经偏高：具名客户与合作方包括 Dell（2026 年 Dell AI 年度合作伙伴奖）、SK Telecom（既是战略投资人又是客户）、一线金融机构（Tier-1 financial institution，MemoryAI 客户）、主权 AI（sovereign）、neocloud 云厂商、以及电信/networking 内存客户。H1 FY26 拿下 7 个新 logo（Q2 单季 5 个）。关键转变：公司正主动从「依赖少数 hyperscaler 大单」多元化到「enterprise + neocloud + sovereign」，目的是降低收入的 lumpiness——但这也意味着放弃了部分规模，把自己更深地绑在竞争最激烈的 AI 基建赛道上。
护城河本质（金融场景比喻）
Penguin 的护城河像一家「拿到了大甲方框架协议的区域性专业工程承包商」——不像英伟达（卖芯片=印钞机）或 Micron/SK海力士（规模化建材巨头）那样有宽护城河。它的黏性来自「一旦帮你把 AI 工厂建起来并托管运维，你很难中途换承包商」（类似银行核心系统供应商的切换成本），加上 Stratus 容错和「零失效」内存这种利基 know-how。但它夹在 Dell/Super Micro（更大的系统集成商）和 Micron/SK海力士（更大的内存厂）之间，规模劣势明显。SKT $200M 战略投资 + Dell 合作是它的「资质背书」，类似小承包商拿到了大甲方的长期框架协议——能撑一段路，但改变不了它「体量小、夹在中间」的结构性位置。

📦 模块一：商业模式

这家公司到底做什么生意？

商业模式类型：产品销售(项目制) + 经常性服务/软件 + 周期性内存销售 (混合型)
核心产品/服务
三大分部：① Advanced Computing（Penguin Computing / OriginAI / Stratus 品牌）——AI/HPC 集群设计部署、浸没式液冷、AI 集群管理软件、托管服务、容错计算，是「AI 工厂」总包业务；② Integrated Memory（SMART Modular 品牌）——DRAM 模组、「零失效」内存、SSD/闪存、CXL 内存扩展（MemoryAI KV cache server，单机可加 11TB，主打推理内存墙）；③ Optimized LED（Cree LED 品牌）——LED 照明芯片，萎缩中、逐步退出。
客户群体
B2B / G2B 为主：企业（enterprise）、主权 AI（sovereign）、neocloud 云厂商、电信/networking、数据分析、金融机构。曾高度依赖 hyperscaler，现主动多元化。客户集中度与单季大单节奏是收入波动主因。
地理分布
全球部署，总部美国加州 Fremont；内存与系统业务面向北美、亚洲（含 SK Telecom 韩国战略合作）、欧洲主权/企业客户。
收入结构
Q2 FY26 收入结构：Integrated Memory $172M（50%，+63% YoY，成长引擎）、Advanced Computing $116M（34%，−42% YoY，受 Penguin Edge 退出 + hyperscaler 硬件下滑拖累）、Optimized LED $56M（16%，−7% YoY，萎缩）。FY26 全年指引：收入 +12%（约 $1.5B）、GAAP EPS $1.30、non-GAAP EPS $2.15。FY25 曾 +17% 收入 / +53% non-GAAP EPS。
